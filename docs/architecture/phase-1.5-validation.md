# Phase 1.5 — Architecture validation and decision closure

**Reviewed** 24 November 2026  
**Recommendation** Approve Phase 2 with the runtime correction as its first step. Owner approval is pending.

Use one Nx/npm workspace with `apps/web` for public Nuxt SSR, `apps/admin` for the custom Nuxt editor, and `apps/cms` for Keystone on the private network. PostgreSQL 18 stores content, revision and session records. Admin and Web call Keystone through separate server-side paths. Private S3-compatible storage holds editorial media. Deliver the gallery as an optional client enhancement of the server-rendered portfolio. Run the production services behind Nginx on one Linux VPS.

The review checked exact registry manifests and computed semver compatibility, inspected the integrity-verified Keystone package for session, CLI, Prisma client and transaction behavior, and confirmed that the local Docker daemon responds. Combined install, runtime, browser and recovery proof belongs to the acceptance gates below.

## Environment changes and decision gate

- Pin Node `24.22.3` and npm `11.19.1` for Phase 2, with matching runtime checks in development, CI, and container smoke tests. Record the exact resolved Nx, Nuxt and Keystone stack in the npm lockfile after a clean install.
- Use the working Linux Docker/Compose environment with a disposable PostgreSQL 18 instance. Select and record an exact supported image patch or digest and use matching PostgreSQL 18 backup and restore tools. Keep its credentials and volume separate from other work.
- Confirm the provider and owner choices in the findings table by their named gates. The Foundation can proceed with local/test defaults after approval.

Phase 2 is ready for approval because it has a bounded change set and executable checks. Its scope is the Nx workspace, minimal app shells and tokens, reproducible package tooling, SSR smoke evidence, and the isolated Keystone/PostgreSQL proof. The Project workflow, editor, real content, WebGL scene and production infrastructure begin in their documented phases.
